# `sundial`
 
Game-independent\* Luanti engine mod adding a sundial, making use of dynamic shadows.

## Specification

Assumes `shadow_sky_body_orbit_tilt` = 45, other values *may* work but no guarantees.

DOES NOT WORK WITHOUT `enable_dynamic_shadows`

\* Needs `basic_materials` and optionally `dye` for the recipe
